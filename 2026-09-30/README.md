# 2026-09-30 — Week-ahead CGM hypoglycemia risk GVU

Prototype of the monitoring/care opportunity: next-week severe-hypoglycemia probability from one week of CGM summary metrics (TBR, %CV, GMI), revised by a Generator–Verifier–Updater loop.

## Run

```bash
python3 gvu_week_ahead_hypo.py
```
